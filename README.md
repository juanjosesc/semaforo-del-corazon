# Semáforo del Corazón

Juego educativo para móvil sobre síndrome metabólico: en cada paciente se buscan las 5 pistas
(criterios armonizados ATP III / IDF / AHA-NHLBI) y se enciende el semáforo (verde 0–1, amarillo 2, rojo 3 o más).
Incluye el simulador «Mide tu semáforo».

HTML estático, sin dependencias ni paso de construcción. Para probar en local: abrir `index.html`.
Se publica en Netlify con cada push a `main`.
